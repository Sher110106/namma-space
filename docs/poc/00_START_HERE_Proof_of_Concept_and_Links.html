Judge path

  1. Open the link and click once.
  2. Walk into a wall; the controller stops you.
  3. Press M and click the minimap to jump.
  4. Press C for a held-out photo beside the render.
  5. Press T for the tour; it ends with the machine's frame rate.
  6. Read the results card.

The path takes about ${viewer.judge_path_minutes} minutes on a supported browser. It is the same route shown in the demo video.

Controls
WASD or arrow keys: walk · mouse drag: look · M: map · C: reality check · T: tour · R: respawn · H: help · Esc: release pointer lock

What this proves: one phone capture, a metric frame, compact SPZ assets, walkable collision and a browser renderer. The run and evaluation records hold the measurements.

Known limits
One indoor room is the Round One scope. Search, routes, multiple floors and WebXR AR are not built. Very slow or software-only graphics may need the preview or the offline video.

If the link fails
Open the offline zip with the command in START_HERE.txt. If a browser cannot run WebGL2, use the recorded video and the static result pairs.
