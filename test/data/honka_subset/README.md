# honka_subset

30 frames from the MuSHRoom `honka` room, iPhone long capture: `frame_00101.jpg` to `frame_00188.jpg`, every
third frame, 738 x 994 px, copied unchanged from `iphone/long_capture/images/`.

Used by the root rehearsal (`./ns run --frames test/data/honka_subset/frames --name rh-honka30 --quick`) and by
test/e2e. It is a public sample, not our capture.
